WHAT IT IS
----------
Paste the problem statement and your buggy competitive-programming /
LeetCode solution. Counterexample Finder uses BharatCode to write a
guaranteed-correct brute-force solution and a random test generator, then
RUNS both in your browser and returns the SMALLEST input that breaks your
code, along with a plain-language root cause.

This is the "AI proposes, code verifies" pattern: the AI never asserts a bug —
it writes a reference and your browser proves the mismatch with real inputs
and real outputs. No hallucinated explanations, no sandbox, no server cost.

HOW IT USES THE BHARATCODE API
-------------------------------
- Endpoint: https://bharatcode.ai/api/model/v1/chat/completions (OpenAI-compatible)
- Model:    qwen-3.8-27b
- Call A (generate): produces { entryName, bruteForceCode, generatorCode,
  maxInputSize, testCount } using strict JSON-schema structured output.
- Call B (explain): explains the root cause from the REAL failing input +
  both outputs (free text, so it cannot invent).
- Refuses to trust the model blindly: if the brute-force and your code both
  fail on the same generated input, it reports a "reference check" instead of
  a false positive.
- Resilient to shared capacity: retries 503/5xx/429 with backoff + jitter,
  honours Retry-After, 180s timeout, drops optional params on 400, and treats
  empty / truncated output as an error.

RESULTS (eval suite in evals/, qwen-3.8-27b on BharatCode)
---------------------------------------------------------

- False positives:       0   (a correct solution is never flagged)

RUN IT LOCALLY

2. npm run install:all
3. npm run dev
   -> app on http://localhost:5173   (API on http://localhost:4000)
Without a key it runs in demo mode using the built-in sample.
